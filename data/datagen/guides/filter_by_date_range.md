# Guide: filter_by_date_range

Narrow down a list of items or search results to a specific date range.

## Preconditions

- A list of items, search results, or records is displayed on the screen.
- Date range input fields (such as 'From'/'To' or 'Start'/'End') are visible.

## Steps

1. Locate the date input fields, typically labeled 'From', 'To', 'Start Date', 'End Date', or similar.
2. Click on the start date input field and type or select the desired start date.
3. Click on the end date input field and type or select the desired end date.
4. Click the filter, search, or apply button (e.g., 'Filter', 'Filter by Date', 'Apply Filters') to submit the date range.

## Watch for

- The date fields displaying the correct entered dates.
- A loading spinner or page refresh indicating the filter is being applied.

## Pitfalls

- Typing the date in an incorrect format (e.g., MM/DD/YYYY vs YYYY-MM-DD) if the input doesn't auto-format.
- Forgetting to click the submit/filter button after entering the dates.

## Variants

- **Only one bound is required (e.g., 'before July 1' or 'after January 1')** — Fill in only the relevant date field (either 'To' or 'From') and leave the other blank.
- **The date input uses a calendar picker instead of direct typing** — Click the calendar icon, navigate to the correct month and year, and select the specific day.

## Done when

The list of items updates, and the URL or page content reflects the applied date constraints.
