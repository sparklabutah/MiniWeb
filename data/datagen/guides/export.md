# Guide: export

Export data by selecting the desired scope and format, then triggering the download.

## Preconditions

- The user is on a page containing the data to be exported, or on a dedicated settings/export panel.

## Steps

1. Locate the export section, button, or link on the page.
2. If dropdown menus are present, select the desired data scope or category to export.
3. If format options are available, select the target file format (such as CSV, PDF, SVG, or JSON).
4. Click the primary action button (e.g., 'Export', 'Download', or 'Save') to initiate the process.
5. If prompted with a file-saving dialog, optionally customize the filename and click 'Save' or 'Confirm' to complete the download.

## Watch for

- A browser download notification or progress bar indicating the file is downloading.
- A success toast message confirming the export was successful.

## Pitfalls

- Triggering the export button before verifying that the correct format and data scope dropdowns are selected.
- Navigating away from the page or closing the tab before the download has fully completed.

## Variants

- **A direct export link is available (e.g., 'Export CSV')** — Click the link directly to trigger an immediate download without configuring options.
- **The export options are located inside a settings or profile menu** — Navigate to the settings or profile page first, then locate the export controls.

## Done when

The file is successfully downloaded to the local system and visible in the browser's download history.
