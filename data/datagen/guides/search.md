# Guide: search

Find content by typing a text/natural-language query

## Preconditions

- A search input field (often labeled 'Search', 'Find', or marked with a magnifying glass icon) is visible on the page.

## Steps

1. Click on the search input field to focus it.
2. Type the desired search query or keywords.
3. Submit the search by either pressing the Enter key or clicking the adjacent search button (often labeled 'Search', 'Go', or represented by a magnifying glass icon).

## Watch for

- The search input field displaying the typed text.
- The page reloading or updating to display a list of results matching the query.

## Pitfalls

- Typing the query but forgetting to submit it (failing to press Enter or click the search button).
- Accidentally clicking a clear button (often an 'X' icon inside the input field) instead of the search button.

## Variants

- **the search input is part of a larger filter form with dropdowns** — type the search query, configure any required dropdown filters, and then click the form's submit or filter button.

## Done when

The page updates to show search results, often indicated by a change in the URL or a header indicating results matching the query.
