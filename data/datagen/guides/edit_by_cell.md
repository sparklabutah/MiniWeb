# Guide: edit_by_cell

Enter or update data directly within a grid or table interface, optionally adding new rows, and commit the changes.

## Preconditions

- A grid, spreadsheet, or table editor interface is open on the screen.

## Steps

1. If entering a new record and no empty row is available, click the button to add a new row.
2. Click directly inside the target cell to activate its input field.
3. Type the desired value into the active cell.
4. Repeat the click-and-type process for all other cells requiring updates.
5. Click the save button (typically labeled 'Save Changes' or similar) to commit the edits to the database.

## Watch for

- The cell input field displaying a cursor or highlight border, indicating it is ready for typing.
- The typed text appearing correctly inside the cell boundaries.

## Pitfalls

- Clicking away from an active cell before finishing typing, which may discard the uncommitted cell value.
- Forgetting to click the final save button in interfaces that do not support autosave.

## Variants

- **the interface supports automatic saving** — Omit the final save button click, as changes are committed upon deselecting the cell or pressing Enter.
- **data needs to be copied from another source tab** — Switch to the source tab, copy or note the value, switch back to the grid tab, and type it into the active cell.

## Done when

A success notification appears, or the save button becomes temporarily disabled, indicating all changes have been successfully committed.
