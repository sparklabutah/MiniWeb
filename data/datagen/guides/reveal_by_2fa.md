# Guide: reveal_by_2fa

Reveal protected information by initiating a verification request, retrieving a 2FA code from a messaging or email tab, and entering it back into the verification prompt.

## Preconditions

- The user is on a page displaying a masked credential or protected content with a 'Reveal' or 'Show' option.
- A separate tab or application is open where verification codes (e.g., SMS, email, chat) are received.

## Steps

1. Click the 'Reveal' or 'Show' button next to the protected content to trigger the verification prompt.
2. Switch to the tab or application where verification codes are received.
3. Locate and open the latest message containing the verification code.
4. Note down or copy the verification code.
5. Switch back to the original tab containing the verification prompt.
6. Enter the verification code into the input field.
7. Click the 'Verify' or 'Submit' button to complete the process.

## Watch for

- A verification input field appearing after clicking 'Reveal'.
- The verification code being accepted without error messages.
- The masked content changing to plain text.

## Pitfalls

- Using an outdated verification code from a previous attempt.
- Accidentally closing the verification prompt tab while retrieving the code.

## Variants

- **The verification code is sent via a chat application** — Scroll through the conversation list to find the sender, click the conversation, and copy the code.
- **The verification code is sent via email** — Refresh the inbox, open the latest email from the service, and copy the code.

## Done when

The protected content (e.g., password) is successfully revealed and visible on the screen.
