# Guide: message_from_free_text

Send a text message to a recipient, channel, or thread by typing into the message input field and submitting it.

## Preconditions

- The target conversation, channel, thread, or recipient's chat window is open and active on the screen.

## Steps

1. Locate the text input area or text box designated for typing messages (often labeled with placeholders like 'Type a message', 'Message...', or 'Reply...').
2. Click inside the text input area to focus it.
3. Type the desired message content using the keyboard.
4. Click the 'Send', 'Reply', or 'Submit' button next to the input field, or press Enter if supported by the platform.

## Watch for

- The typed text appearing clearly in the input box before sending.
- The input box clearing out immediately after clicking send.
- The sent message appearing at the bottom of the chat history or thread.

## Pitfalls

- Drafting the message in the input box but failing to click the send button or press Enter, leaving it unsent.
- Sending the message to the wrong active chat window if multiple tabs or chats are open.

## Variants

- **The platform uses a multi-line textarea instead of a single-line input** — Type the message and look for a dedicated 'Send' or 'Reply' button to submit, as pressing Enter might only insert a new line.

## Done when

The message is visible in the conversation history with a timestamp, indicating it has been successfully sent.
