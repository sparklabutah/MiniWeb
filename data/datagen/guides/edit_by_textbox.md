# Guide: edit_by_textbox

Adds a customizable text box to a design canvas, inputs the specified text, applies requested styling, and saves the changes.

## Preconditions

- The design canvas or image editor is open.
- The 'Add Text' tool or button has already been clicked, initiating the text insertion process.

## Steps

1. Click on the design canvas to place the new text box, or click the specific text style option (e.g., heading, body text) to insert it.
2. Type or paste the requested text into the active text box.
3. Select the text or click the text box frame to activate the text formatting toolbar or sidebar.
4. Adjust the text styling (such as font, size, color, alignment, or effects) using the formatting controls to match any specified design requirements.
5. Optionally, click and drag the text box boundaries to resize it, or drag the center to reposition it on the canvas.
6. Click outside the text box area to deselect it and confirm the layout.
7. Click the save, apply, or export button to commit the design changes.

## Watch for

- A blinking text cursor indicating the text box is active and ready for input.
- The text updating in real-time on the canvas as you type.
- Styling changes (like color or font size) reflecting immediately on the selected text.

## Pitfalls

- Failing to clear the default placeholder text, leaving unwanted words in the final design.
- Clicking outside the text box before typing, which may delete the empty text box in some editors.
- Forgetting to click the final 'Save' or 'Apply' button, causing the added text to be lost.

## Variants

- **The text box pre-populates with default placeholder text** — Double-click the text box or press Ctrl+A (Cmd+A) to select all placeholder text before typing the new content.
- **Formatting options are not visible in a floating toolbar** — Look for a properties or styling panel on the left or right sidebar of the editor interface.

## Done when

The text box displays the correct text and styling on the canvas, and the editor indicates the design has been saved or updated.
