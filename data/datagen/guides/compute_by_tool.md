# Guide: compute_by_tool

Use an on-page calculator, converter, or tool to compute a result based on specific inputs.

## Preconditions

- The browser is open to a page containing the tool, or a navigation page where the tool can be accessed.

## Steps

1. Navigate to the specific calculator, converter, or tool page if not already there.
2. Locate the input fields (such as text boxes, sliders, or dropdowns) for the required parameters.
3. Enter or adjust the input values to match the target specifications.
4. If applicable, select the correct units or options from the 'From' and 'To' dropdown menus.
5. Click the primary action button (e.g., 'Calculate', 'Convert', 'Compute') to execute the calculation.

## Watch for

- The page updating to display a new calculated value, result box, or success message.
- Validation errors indicating that an input value is out of range or in the wrong format.

## Pitfalls

- Entering values into the wrong fields (e.g., swapping height and weight).
- Forgetting to update the unit dropdowns, leading to an incorrect conversion or calculation.
- Not clicking the final calculation button after updating the input fields.

## Variants

- **The input is a slider instead of a text field** — Drag or click the slider handle to adjust it to the target value before computing.
- **The tool has default units that do not match the request** — Open the unit dropdowns and select the requested units before entering the values.

## Done when

The calculated output, converted value, or result summary is clearly displayed on the screen.
