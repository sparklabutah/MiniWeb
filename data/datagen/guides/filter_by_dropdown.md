# Guide: filter_by_dropdown

Narrow results by selecting a dropdown value (incl. category search)

## Preconditions

- A list of items (such as search results, logs, products, or streams) is visible on the page.
- One or more dropdown filter menus are present above or alongside the list.

## Steps

1. Locate the target dropdown filter menu corresponding to the desired criteria (e.g., Category, Status, Type).
2. Click on the dropdown menu to expand the list of available options.
3. Select the desired filter option from the list.
4. If the results do not update automatically, locate and click the submission button (e.g., 'Filter', 'Apply', 'Search').

## Watch for

- The dropdown menu text updating to display the selected option.
- A loading spinner or visual refresh indicating the list is updating.
- The number of displayed items changing to reflect the applied filter.

## Pitfalls

- Forgetting to click the 'Filter' or 'Apply' button on sites that do not support automatic updates.
- Selecting an option but clicking outside the dropdown before the selection registers.

## Variants

- **The site automatically updates results upon selection** — Omit clicking any submission button; simply verify the list updates after selecting the option.
- **Multiple filters need to be applied** — Repeat the dropdown selection steps for each target filter before clicking the submission button.

## Done when

The dropdown displays the selected value, and the list of results has updated to match the filter criteria.
