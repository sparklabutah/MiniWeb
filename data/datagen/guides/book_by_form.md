# Guide: book_by_form

Book or request an appointment by filling out a scheduling form with date, time, and other required details, then submitting it.

## Preconditions

- The browser is on the scheduling page or a page containing a link/button to book/schedule an appointment.

## Steps

1. Navigate to the booking/scheduling form page if not already there.
2. Select the appointment type, provider, or service from the dropdown menu if required.
3. Input the preferred date using the date picker or by typing it into the date field.
4. Select or input the preferred time slot from the available options.
5. Fill in any additional required fields, such as visit type, reason for visit, or personal contact details.
6. Click the submission button (e.g., 'Book Appointment' or 'Request Appointment') to submit the form.

## Watch for

- The date and time fields updating to reflect the chosen slot.
- Validation errors or red highlights on fields if any required information is missing or formatted incorrectly.

## Pitfalls

- Failing to select the correct appointment type or provider, which may filter out the desired date/time slots.
- Typing the date in an incorrect format if the date picker does not auto-format it.
- Clicking away before the form submission fully processes and confirms the booking.

## Variants

- **The form requires selecting a specific provider or service type first** — Locate the dropdown menu for 'Provider' or 'Appointment Type' and select the specified option before choosing a date and time.
- **The form includes optional text fields like 'Reason for Visit' or 'Additional Notes'** — Type the relevant context or reason into the text area before submitting.

## Done when

A confirmation message (e.g., 'Appointment scheduled successfully!') appears on the screen, or the page redirects to a booking confirmation page.
