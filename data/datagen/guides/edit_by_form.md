# Guide: edit_by_form

Edit an existing record's fields through a form and save the changes.

## Preconditions

- The edit form for the target record is open, or the record is displayed with an edit option available.

## Steps

1. Locate the specific input fields (such as text boxes, dropdowns, date pickers, or sliders) that need to be updated.
2. Click on each target field to focus it.
3. Modify the field's value by typing new text, selecting a different option from a dropdown, or adjusting the control.
4. Scroll to find the form's submission button (typically labeled 'Save', 'Save Changes', or 'Submit').
5. Click the submission button to apply and save the updates.

## Watch for

- The input fields visually updating to reflect the newly entered or selected values before saving.

## Pitfalls

- Navigating away from the page or closing the form without clicking the save/submit button, which discards all changes.
- Accidentally clearing or overwriting required fields that were not meant to be changed.

## Variants

- **the field is a dropdown menu** — Click the dropdown to open the options, then click the desired option to select it.
- **editing an inline item like a chat message or title** — Click the 'Edit' icon or button next to the item first to make the input field editable.
- **the field is a slider or range input** — Drag the slider handle or use the keyboard arrow keys to adjust the value to the target setting.

## Done when

The form closes, the page redirects, or the updated values are displayed on the saved record.
