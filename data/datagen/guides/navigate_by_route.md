# Guide: navigate_by_route

Go to a page by clicking a link/menu/tab

## Preconditions

- The current page contains a link, menu item, tab, or card that leads to the target destination.

## Steps

1. Locate the navigation element (such as a link, menu item, tab, card, or list item) representing the target destination.
2. Click on the navigation element.
3. If the target page is nested, repeat the process by locating and clicking the next sub-navigation element or specific item link.

## Watch for

- The URL in the address bar changing.
- The page content updating to match the selected destination.

## Pitfalls

- Clicking on a similar but incorrect link (e.g., a different product or post with a similar name).
- Clicking on non-interactive text instead of the actual hyperlink.

## Variants

- **the target is nested within a category or menu** — Click the parent category/menu first, then click the specific target item.
- **the target is in a sidebar or header navigation** — Locate the global navigation bar and click the corresponding tab or link.

## Done when

The destination page has fully loaded, displaying the correct URL or page title.
