# Guide: sort_by_form

Sort a listing by operating a sort control

## Preconditions

- A list of items (such as products, projects, or streams) is visible on the screen.
- A sorting control (dropdown menu, select element, or sorting links/tabs) is present near the listing.

## Steps

1. Locate the sorting control, which is typically labeled 'Sort', 'Sort By', or displays the current active sorting criteria.
2. If the control is a dropdown or select menu, click it to open the options, then select the desired sorting criteria.
3. If the sorting control requires manual submission, locate and click the 'Apply', 'Filter', 'Search', or 'Submit' button associated with the form.
4. If the sorting control consists of direct links or tabs (e.g., 'Popular', 'Latest', 'Oldest'), click the link corresponding to the desired sort order.

## Watch for

- The list of items visibly reordering.
- The URL updating to include a sorting query parameter (e.g., '?sort=...').
- The selected sorting option remaining highlighted or displayed as the active choice in the control.

## Pitfalls

- Selecting the option in a dropdown but forgetting to click the 'Apply' or 'Filter' button when the page does not auto-submit.
- Confusing filtering controls (which restrict what is shown) with sorting controls (which change the order of what is shown).

## Variants

- **The dropdown automatically updates the list upon selection** — Simply select the option from the dropdown without looking for a submit button.
- **The sorting options are presented as clickable column headers or text links** — Click directly on the header or link representing the desired sort key.

## Done when

The listing updates to display the items in the requested sorted order.
