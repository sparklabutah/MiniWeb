# Guide: save_by_form

Save a document or file to the user's account or cloud storage using the interface's save button or form.

## Preconditions

- The user is viewing a document, file, or detail page that contains an option to save it to their account, files, or documents.

## Steps

1. Locate the save action button, which may be labeled 'Save', 'Save to my files', or represented by a save/favorite icon.
2. Click the save button.
3. If a dialog or form appears asking for a destination folder or file name, select the appropriate options and click the confirmation 'Save' or 'Submit' button.

## Watch for

- A confirmation toast message indicating the file has been successfully saved.
- The save button text changing to 'Saved' or showing a checkmark.

## Pitfalls

- Confusing the local 'Download' action with the cloud 'Save' action when the goal is to save the file within the platform's storage.

## Variants

- **The save button immediately saves the file without opening a dialog** — Click the button and wait for the success confirmation toast or button state change.

## Done when

A success notification appears (e.g., 'Saved to Documents') or the save button state updates to indicate it has been saved.
