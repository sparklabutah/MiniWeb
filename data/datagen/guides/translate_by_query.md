# Guide: translate_by_query

Translate a given text from one language to another using an online translation tool.

## Preconditions

- The translation tool interface is open on the screen.

## Steps

1. Click inside the text input area designated for the source text.
2. Type or paste the text you want to translate.
3. If the source language is not automatically detected correctly, click the source language selector and choose the correct language from the list.
4. Click the target language selector and select the desired language for the translation.
5. Wait for the translated text to appear in the output area.
6. Highlight or copy the translated text if needed for subsequent tasks.

## Watch for

- The character count updating as you type.
- The output area displaying the translated text in the correct target language script.

## Pitfalls

- Accidentally typing the text into the output field instead of the input field.
- Selecting the wrong language from a long dropdown list of similar-looking language names.

## Variants

- **The correct source and target languages are already selected by default** — Skip the language selection steps and directly enter the text to get the translation.

## Done when

The translated text is fully rendered in the output panel.
