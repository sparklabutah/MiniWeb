# Guide: write_executable_program

Write, edit, and execute code within an online code editor.

## Preconditions

- The browser is open to the code editor interface containing a code input area and an execution button.

## Steps

1. Click inside the code editor text area to focus the cursor.
2. Type, edit, or paste the required code into the editor.
3. Click the button to run or execute the code.

## Watch for

- The output panel updating with the results of the code execution.
- The exit code displaying '0' indicating successful execution without errors.

## Pitfalls

- Typing code without first clicking inside the text area to focus the cursor.
- Clicking 'Run Code' before the code has finished typing or updating.

## Variants

- **Starting from a snippet gallery or dashboard** — Click on the desired code snippet card and select the option to open it in the editor before writing code.

## Done when

The output panel displays the expected program output.
