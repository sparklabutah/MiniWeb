# Guide: carry_info_cross_site

Transfer a specific piece of information, such as an identifier, email, name, or amount, from a source website to a destination website by copying it before switching tabs.

## Preconditions

- The source website containing the required information is open and active.
- The destination website is open in a background tab.

## Steps

1. Locate the target value (e.g., name, email, ID, or amount) on the current page.
2. Select the target value using the mouse cursor.
3. Copy the selected value to the clipboard using a keyboard shortcut or right-click menu.
4. Switch to the browser tab containing the destination website.

## Watch for

- The target text is highlighted correctly without extra leading or trailing spaces.
- The destination tab successfully loads and becomes the active window.

## Pitfalls

- Copying surrounding whitespace or labels instead of just the raw value.
- Accidentally overwriting the clipboard before pasting the value into the destination site.
- Switching to the wrong tab or window.

## Variants

- **The text cannot be selected or copied directly from the page** — Carefully read and memorize the value, or manually type it into a temporary text area before switching tabs.

## Done when

The destination tab is active and the cursor is ready to paste or input the carried value.
