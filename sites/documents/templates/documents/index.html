API Endpoints
  • GET /sites/documents/api/documents - List documents (?q=, &sort=, &folder_id=, &owner_id=, &starred=true, &trashed=true)
  • GET /sites/documents/api/documents/<id> - Get single document
  • POST /sites/documents/api/documents - Create document (JSON: title, content, owner_id, folder_id)
  • PUT /sites/documents/api/documents/<id> - Update document (JSON: title, content)
  • POST /sites/documents/api/documents/<id>/star - Toggle star
  • POST /sites/documents/api/documents/<id>/share - Share (JSON: user_id, permission)
  • POST /sites/documents/api/documents/<id>/trash - Trash/restore (JSON: action=trash|restore)
  • POST /sites/documents/api/documents/<id>/delete - Permanently delete
  • GET /sites/documents/api/documents/<id>/revisions - Revision history
  • GET /sites/documents/api/folders - List folders
  • GET /sites/documents/api/stats - Document statistics
  • GET /sites/documents/api/search?q= - Search documents
  • GET /sites/documents/api/export?owner_id=&folder_id=&format=json|csv - Export documents
  • POST /sites/documents/api/login - Login (JSON: username, password)
  • GET /sites/documents/api/users - List users
