This website is a team messaging and collaboration workspace, similar to Slack/Microsoft Teams. Meridian Systems employees use it for channel-based communication, threaded discussions, file sharing, and emoji reactions.

Data source: data_sources/team-chat/ — channels.json (10 channels), messages.json (75 messages), threads.json (7 threads), reactions.json (30 reactions), users.json (12 users). Derived from Meridian Systems email dataset.

Real-world model: Slack / Microsoft Teams. Sidebar with channel list, main message area with threaded replies, emoji reactions, file uploads, and member directory.
