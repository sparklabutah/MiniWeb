This website simulates a note-taking and whiteboard collaboration platform (Notion/Miro style). Users can create, organize, and search notes across notebooks, collaborate on whiteboards with drag-and-drop elements, and share boards with teammates.

Data source: data_sources/handwritten-notes-whiteboards/ (notes.json, notebooks.json, whiteboards.json, users.json)
Entities: Notes, Notebooks, Whiteboards (with canvas elements), Users
Key features: Rich note editing, notebook organization, whiteboard canvas with positional elements, collaboration via sharing/inviting, search (keyword + semantic), image upload placeholders, export in multiple formats
