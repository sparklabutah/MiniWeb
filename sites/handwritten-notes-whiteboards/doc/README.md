# NoteCanvas (`handwritten-notes-whiteboards`)

A notes and whiteboard app in the spirit of Apple Notes, Notion and Miro. Every
note has a text body and a freeform drawing canvas. Whiteboards hold sticky
notes, shapes and text that can be dragged around.

- URL: `/sites/handwritten-notes-whiteboards/` (simulated domain `notecraft.app`)
- Data split: training site

## Pages

| Route | Page |
|---|---|
| `/` | All Notes: search, tag chips, sort (recent, title, created), + New Note |
| `/note/<id>` | Note editor: title, text, drawing canvas (Text/Draw/Both modes, pen, eraser, brush-size slider), Add image, pin, invite by email, delete |
| `/note/<id>/image/edit` | Image editor for a note's image (crop, resize, contrast, vibrance) |
| `/whiteboards` | The user's whiteboards |
| `/whiteboard/<id>` | Whiteboard canvas with draggable elements |
| `/login` | Sign-in form |

`/note/new` creates a note and opens the editor. `/notebooks`, `/notebook/<id>`
and `/search` redirect to the notes list. JSON endpoints under `/api/` cover
notes, notebooks, whiteboards (elements, move, share, invite), search, pinning,
reordering, upload and export.

## Interactions and macros

- Search notes: `search`
- Create a note, write text, invite a collaborator: `create_by_form`
- Draw or sign on the canvas: `sign_by_freeformdrawing`, `edit_by_image`
- Set the brush size: `configure_by_form`
- Edit a note's fields: `edit_by_form`
- Reorder notes: `edit_by_ranking`
- Drag elements on a canvas: `reposition_by_drag`
- Pin or unpin a note: `toggle_relationship`
- Attach an image to a note, delete a note: `upload_file`, `delete_from_table`

The per-macro UI locations are listed in `data/macro_locations.yaml` under `handwritten-notes-whiteboards`.

## Data

- Tables: `handwritten_notes_whiteboards_notes`, `..._notebooks`,
  `..._whiteboards`, `..._users`.
- Login reads `session["user_id"]`, so the global auto-login signs the user in
  as user 1.
- Saved drawings are detected server-side (`has_drawing`), so signature tasks
  can be graded.
- Note images are deterministic placeholder PNG/JPG files generated by
  `sites/handwritten-notes-whiteboards/images.py` into
  `data/static/generated/`. The image-editor transforms run server-side with
  PIL.
- Creating notes or uploading images emits `file_created`, which syncs a copy
  to cloud storage and sends an email. Logging in emits `signup`.
