Data source: data_sources/map-services/ — locations.json (45 POIs), routes.json (18 saved routes), saved_places.json (user favorites), search_history.json, users.json. All locations in fictional Lakeport, WA.

Real-world model: Google Maps / Apple Maps. Map-centric interface with search bar, POI markers, directions panel, and saved places sidebar.

Temporal dynamics: Not applicable — map data is static. Could be extended with real-time traffic simulation.

Domain-specific notes: Lakeport streets include Main St, Oak Ave, Cedar Blvd, Elm Dr, Pine Rd, Harbor Dr. POI categories: restaurants, shops, parks, services, entertainment. Distance calculations use haversine formula.
