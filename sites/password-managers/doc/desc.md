This website simulates a password manager application (1Password / LastPass / Bitwarden). The interface features a dark-themed vault management dashboard with security reports, audit logs, and password generation tools.

Data source: data_sources/password-managers/ (entries.json, vaults.json, users.json, audit_log.json, security_report.json)
Searching method: keyword match and simple keyword-overlap semantic search over entry titles, URLs, usernames, notes, and tags
