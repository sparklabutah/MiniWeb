This website simulates an online Python IDE (GeeksforGeeks IDE, Repl.it). It serves a snippet gallery, an in-browser code editor, and executes Python code server-side with a timeout and import restrictions.

Data source: data_sources/code-editor-execution/snippets.json, data_sources/code-editor-execution/users.json
Interaction method: browse snippet gallery, edit and run Python code in the editor
