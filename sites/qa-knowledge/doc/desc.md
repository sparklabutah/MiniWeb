This website simulates a Q&A programming knowledge platform (Stack Overflow style). The interface emulates the classic Stack Overflow experience: question lists with vote counts, tag-based navigation, user profiles with reputation, and answer threads with voting and acceptance.

Data source: data_sources/stackexchange-augment/ (overlay format with questions, answers, and users arrays)
Searching method: keyword match for search_by_query, keyword-overlap scoring for search_by_semantic
