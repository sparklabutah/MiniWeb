This website is an insurance and lending portal, similar to State Farm/Progressive online account management. Users can view policies, file claims, manage loans, make payments, and compare coverage options.

Data source: data_sources/insurance-loans/ — policies.json (11 insurance policies), claims.json (5 claims), loans.json (6 loans), payments.json (23 payments), users.json. All synthetic data linked to MiniWeb universe users.

Real-world model: State Farm / Progressive / LendingTree. Dashboard with policy overview, claims tracker, loan management, and payment history.

Temporal dynamics: Not applicable — insurance/loan data is event-driven, not time-varying.

Domain-specific notes: Cross-references banking site for payment accounts. Policies span auto, home, health, life, and umbrella coverage. Loan types include auto, personal, and home equity. E-signature support for policy changes.
