This website simulates a visual step-by-step how-to guide platform (wikiHow/Instructables). Users browse, search, filter, bookmark, rate, and create illustrated tutorial guides across categories like home improvement, cooking, tech setup, crafts, gardening, auto care, fitness, and productivity.

Data source: data_sources/visual-how-to-guides/ (guides.json, categories.json, users.json, comments.json, bookmarks.json, ratings.json, reactions.json)
Searching method: keyword match and semantic (keyword-overlap scoring)
