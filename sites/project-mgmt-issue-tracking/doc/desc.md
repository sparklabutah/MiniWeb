This website simulates a project management and issue tracking tool (Jira/Linear). The interface is modeled after Jira with Kanban board views, sprint management, backlog grooming, and issue CRUD operations.

The site represents the internal issue tracker for Meridian Systems, a software company with several active projects: MeridianFlow (workflow automation), MeridianVault (document storage), MeridianLens (analytics dashboard), Internal Tools, and Website Redesign.

Data source: Jira social repository (https://github.com/marcoortu/jira-social-repository), adapted into projects, issues, comments, sprints, and users JSON files.
