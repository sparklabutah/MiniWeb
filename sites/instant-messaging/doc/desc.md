This website simulates a personal instant-messaging app (WhatsApp Web / Telegram Desktop). The interface presents Alex Rivera's conversations with family, friends, and a recent date, modeled after WhatsApp Web's dark-themed split-pane layout: a sidebar listing conversations sorted by recency, and a main chat panel showing the message thread.

Data source: data_sources/instant-messaging/ (conversations.json, messages.json, users.json, media.json)
Searching method: substring match across message text, contact names, and conversation names
