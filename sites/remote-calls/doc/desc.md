This website simulates a video meeting and calling platform (Zoom, Microsoft Teams, Google Meet). The interface features a dashboard with upcoming meetings, recent meetings, call log, and recording playback. The front end should emulate modern corporate video conferencing tools.

Data source: data_sources/remote-calls/ (users.json, meetings.json, recordings.json, call_log.json)
Searching method: keyword-overlap semantic search over meeting titles, types, statuses, and participant names
