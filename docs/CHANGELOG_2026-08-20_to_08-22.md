# Changelog — Aug 20–22, 2026

Covers commits `f5fb16b` → `80c708b` plus the current working tree.

---

## Sites

### SheetDeck (spreadsheets-slides)
- Removed the "API Endpoints" panels that exposed backend routes to agents (home + spreadsheet pages).
- Export goes through the simulated-filesystem **Save As** dialog instead of a raw browser download.
- Spreadsheet export defaults to a real **`.xlsx`** (openpyxl, every sheet as a tab, numeric cells typed); presentation export added, defaulting to a real **`.pptx`** (python-pptx, title/body/speaker notes per slide). CSV/JSON/Text remain as options.

### PixShare (multimedia-posting)
- Create Post is now an IG-style 3-step composer: **select 1+ media → edit → share**. Posting requires media.
- Edit step: crop (aspect chips Original/1:1/4:5/16:9 + zoom/position sliders), six filter presets, brightness/contrast/saturation — persisted per image as `media_edits` (gradeable), rendered on the post page.
- `api/upload` no longer stuffs large base64 payloads into the session cookie (4KB browser limit).

### ForumHub (forums)
- **Fixed: every thread read as locked.** `_truthy` treated the corpus's Postgres-style `'f'` as set — 49,988 posts were locked *and* stickied. Comments work again; real locks (`'t'`/`'1'`) still enforce.
- Image posts: optional image on Create Post via the file picker (preview + remove, 3MB cap), rendered through the existing media pipeline (post page + feed thumbnails).
- "Create Post" from a community page preselects that community.

### PeerPortal (conference-review-submission)
- Frontend rebuilt to match openreview.net: maroon navbar with global search (`/search`, FTS over papers + venue match), tagline strip, News card + two-column homepage, forum-style paper pages, tabbed console. All form names/routes unchanged.
- **Fixed: dead 2017 deadlines shown as pending.** Pending review tasks are now scoped to venues with status `under_review`; archived venues display real Accept/Reject decisions instead of eternal "Under Review"; `after_decision` review visibility includes archived.
- Concrete deadlines surfaced everywhere: venue header (submission / review / notification), homepage due lines, and a **"Review due"** column on console pending tasks — pairable with CalendarTodo tasks.

### WebMail (email)
- **Removed the whole-corpus RAM cache.** Derived columns (positional id, user_id, folder, parsed dates, preview) are persisted into `email_emails` by `scripts/migrate_email_derived_columns.py` (byte-identical to the legacy pipeline: 0/8145 mismatches); site queries SQL like every other site. Seeded emails appear without a restart.
- **Fixed cross-session state leak**: the `/api/messages/*` mutation routes (read/star/move/label/delete) persisted by mutating the shared cache; they now write the session-isolated `email_state` overlay.
- Search upgraded to AND-of-tokens matching ("Xfinity statement" now finds "Xfinity Internet statement").
- New archive: `scripts/seed_email_archive.py` — 145 deterministic 2023–2026 emails anchored to other sites' real data (payee bills, SkyLodge bookings, policy renewals, order confirmations, calendar invites, OTP/newsletter filler) for cross-site search tasks.

### LinguaBridge (translation)
- Replaced the tiny word-by-word dictionaries as primary backend with **local NLLB-200** (CTranslate2 int8, 633MB, all 110 directions, ~0.2s/sentence CPU, greedy = deterministic). Fetch once with `scripts/fetch_translation_model.py`.
- Every generated translation is frozen in the `translation_cache` base table (shared, travels with the DB) → recorded == graded. Glossaried requests use the LLM (honors term constraints); dictionaries remain the last-resort fallback.

### SecureBank (banking)
- Account numbers masked (`CHK-••••91`) until a **reveal-by-2FA** flow completes (emailed code → `/verify-payment` → `identity_verified`).
- Loan payments accept a custom amount (was hidden fixed field), clamped to remaining balance in both form and API handlers.

### DesignFlow (design-creative)
- Editor Image tool opens the simulated file picker; picked images are downscaled and placed at natural aspect.
- Image elements: crop (%), rotation, opacity — live preview, persisted only when non-default, honored identically in the SVG export (clipPath + transform groups).

### NoteCanvas (handwritten-notes-whiteboards)
- Image upload moved **inside the note** (Add/Replace/Remove in the editor toolbar + image bar); the standalone sidebar widget that created detached image-notes is removed.

### DocVault (documents)
- Removed its "API Endpoints" panel (last site exposing one); index exports use Save As.

### Cross-site: playback info streams
- `app/playback.py` + shared player: every `[data-mini-player]` video gets a deterministic on-screen info stream (`/_player/timeline`, keyed by page path + title). 2–3 **facts** (promo code / reference # / email / viewer count / guest name / prize amount) are visible only in short spans — agents must scrub to find them (`search_by_playback`). Live on 6 sites with zero per-site work.
- **Promo codes really redeem**: checksum-signed (`PREFIX-XXXXXX`+check char), validated offline by the e-commerce cart; discount by prefix (SAVE 10 / STREAM 12 / VIP 15 / EARLY 20%), applied at checkout and recorded on the order.
- **Audio too**: SoundShelf episode player and SoundWave's bottom playbar carry the same deterministic stream (audio-flavored wording, identical values/spans) — 8 playback surfaces total. Fixed a SoundWave bug where every track played as 3:30 (API field mismatch); real durations now used.
- Docs: "Playback Info Streams" Claude artifact.

### File explorer (shared)
- `data-save-as` links open the Save-As dialog instead of auto-downloading; dialog carries binary payloads (`content_b64` + mime); filenames prefer explicit attributes, then the response's `Content-Disposition`.

## Annotation interface
- **Site-count sampling**: "Sites: 🎲 Auto / 1 / 2 / 3" selector forces the sampled task's site count (`?n_sites=`); companion auto-add respects the chosen cap; fixed a fallback that could return 2 sites on a forced 3.
- **Reverse annotation (prototype)**: write the instruction first, "✨ Infer macros from instruction (LLM)" decomposes it into a macro chain (nodes + subtasks + ops + edges) validated against the registry.
- **Verifier builder**: verified tag now shows **who + when** — "✓ minh · 3d ago" pill next to the task id in the sidebar (tooltip with full text), and "verified by … · N days ago" beside the Verify button.
- **Playback Facts lookup** (`/annotate/playback`): 1,133 videos/tracks/episodes across 8 sites with each hidden fact's type, value, and visible span — filterable; keys verified byte-equal to the live player. JSON at `/annotate/api/playback_facts`.
- Annotate timeline no longer jumps to the end on every tag click (auto-follow only while recording).
