# Data licenses of the WebAtoms (MiniWeb) sites

Checked 2026-10-02 against each source's official page (license field, LICENSE file, terms of use). This is a reading
of public terms, not legal advice: confirm with the university's counsel or tech-transfer office before a public release.

The 44 synthetic sites are generated by us and raise no third-party license question. The 21 sites below seed content
from public datasets. Site identities come from `sites/*/doc/README.md`, the archived build scripts
(`../MiniWeb-archive/cleanup-20260810/scripts/`) and the table schemas.

## Summary

| Status | Sources |
|---|---|
| **Clear** (public domain or permissive; attribution at most) | arXiv metadata, US DOT airfares, USDA FoodData Central, Zenodo Fitbit data, Kaggle Job Dataset (synthetic) |
| **Clear with share-alike / attribution duties** | Wikipedia, Wikinews, Wiktionary, Stack Exchange, OpenStreetMap, Common Pile Pressbooks, Jira social repository (as stated), PeerRead ICLR reviews |
| **Research or non-commercial only, or no license** | wikiHow text via VisualHow (CC BY-NC-SA 3.0, research only), Enron email (no license; privacy), Book-Crossing (research use), TBO hotels (MIT label over likely proprietary content), PeerRead paper text |
| **Upstream terms prohibit reuse** (the uploader's license does not cure it) | WebShop / Amazon products, WebArena Reddit and GitLab data, Google Play apps and reviews, USA Real Estate (realtor.com), GSMArena phones |

## Runtime dependencies

- **Map tiles:** CascadiaMaps loads CARTO basemap tiles at runtime with "© OpenStreetMap & CartoDB" credit. CARTO's
  basemap terms were not checked.
- **Hotlinked images:** Amazon (ShopHub), GSMArena (PhoneCompare) and the VisualHow S3 bucket (StepVista). We do not
  redistribute these files, but the pages depend on third-party hosts that can disappear or object.

## What this means for a release

1. **One license cannot cover the database.** CC BY-SA (Wikipedia, Wiktionary, Stack Exchange, Pressbooks), ODbL
   (OpenStreetMap) and CC BY-NC-SA (wikiHow) are mutually incompatible share-alike licenses. Release the database as a
   collection in which each site's tables keep their source license, and license our own code and synthetic data
   separately (e.g., MIT/Apache for code, CC BY 4.0 for synthetic data).
2. **Do not redistribute the "upstream prohibits" sources as data.** Options per site: regenerate the content
   synthetically (catalog, phones, listings, apps), or ship a build script that fetches it from the original source, as
   WebArena and PeerRead do. The same applies to TBO hotels and the PeerRead paper text.
3. **Drop the unused Book-Crossing tables** (`podcasts_audiobooks_books_raw`, `_ratings_raw`) from any released database.
4. **Replace hotlinked images** with generated placeholders, for both licensing and reproducibility.
5. **Enron:** keep the CMU privacy request in mind; consider swapping in synthetic background mail.
6. **Attribution duties** to implement on the sites or in a NOTICE file: Wikipedia page credits, Stack Exchange author
   links, Wikinews credit, Pressbooks per-book credits, OpenStreetMap/ODbL notice (already shown on the map).
7. **Route precomputation** used the OSRM demo server, whose policy forbids mass downloading; recompute the route
   templates on a self-hosted OSRM before release.
8. **Paper:** add a datasheet / licensing statement listing these sources (the commented-out appendix
   "Datasheet, Licensing, and Ethics" in `docs/paper/CVPR/main.tex`).
